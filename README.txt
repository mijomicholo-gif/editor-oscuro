EDITOR OSCURO - EXPORTACIÓN MP4 MEJORADA

Sube index.html a la raíz del repositorio GitHub Pages, reemplazando el archivo anterior.
El editor comprueba si el navegador admite MP4. Si no, exporta WebM y lo indica claramente; no cambia la extensión de forma engañosa.

Tras subirlo, espera un minuto y recarga la web con Ctrl+F5. Usa Chrome o Edge actualizado y permite las descargas del sitio. La exportación ocurre en tiempo real; mantén la pestaña abierta hasta que aparezca Exportación terminada.
